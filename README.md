MagicCloakCV – Harry Potter Inspired Invisibility Cloak

**Real-Time Invisibility Cloak using OpenCV

A Computer Vision project inspired by the famous Harry Potter invisibility cloak. The system uses OpenCV and HSV color segmentation to detect a specific colored cloth (blue cloak) and replace it with the previously captured background, creating the illusion that the object has become invisible in real time.

✨ Features Real-time webcam-based invisibility effect Background subtraction and replacement HSV color segmentation for cloak detection Adjustable HSV trackbars for different lighting conditions Noise reduction using morphological operations Largest contour extraction for accurate cloak detection Live mask visualization for debugging and tuning

🛠️ Tech Stack Python OpenCV NumPy


🎯 Applications Computer Vision Learning Augmented Reality (AR) Entertainment & Visual Effects Real-Time Background Manipulation Educational Demonstrations
